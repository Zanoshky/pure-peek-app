Before you write

  • Search the open issues first. If yours is there, add a thumbs up or a comment.
  • Check the questions and fixes page.
  • One problem per report makes it faster to fix.

What helps

App version
Settings in Pure Peek, at the bottom.
Phone model and Android version
Android settings, About phone.
The kind of file
Its name ending, like .pdf or .csv, and its size.
Steps
What you did, one step per line, so we can do the same.
Expected and actual
What you thought would happen, and what happened.
A picture or a sample
A screenshot, a short screen recording, or the file itself if it holds nothing private.

Issues on GitHub are public. Before you attach a screenshot or a file, make sure it shows nothing private.

Other ways

Prefer not to use GitHub? Write to support@zanoski.com (write an email).
