How Pure Peek works

Open a file

Pure Peek has no file browser of its own and needs no storage permission. Files reach it the ways Android offers:

Open with
Tap a file in Files, Gmail, Drive or Downloads. When Android asks which app to use, pick Pure Peek, then Always, so that kind of file opens straight away next time.
Share
Share any file, or several, to Pure Peek from another app.
Open files
On home, opens Android's file picker. Pick one file or many.
Open a folder
Pick a folder once and see its files as a grid or a list, newest first or by name. Open one and step through the rest with Previous file and Next file.
Photos
Opens Android's photo picker.
Recent files
Home lists what you opened lately. Turn this off in Settings, Privacy.

If another app always opens a kind of file, Settings, Opening files names it and takes you to its info page, where Open by default, Clear defaults hands the choice back.

The viewer bar

Every file opens with its name, kind and size at the top. The buttons there: Back, Find in this file (where the file has text), About this file, and More. More holds Share, Open with another app and the actions for that kind of file.

About this file shows the size in bytes, the kind, everything the file says about itself, and a SHA-256 checksum on request.

Photos

Photos open at full resolution, drawn in tiles, so zooming into a big photo stays sharp. Pinch to zoom, double tap for actual pixels, double tap again to fit. JPEG, PNG, WebP, HEIC, AVIF, GIF, DNG, BMP and more. Ultra HDR and wide colour photos show in full on screens that can.

About this file lists pixels, megapixels, colour space, camera, lens, exposure, ISO and when it was taken. More has Turn a quarter, Use as wallpaper or contact photo, and Share without location and camera details, which sends a copy with the GPS taken out and leaves the original alone.

PDF

Pages render again at every zoom, so small print stays crisp. More has Go to page, First page, Last page, Copy the text of this page, Print, and on dark looks, Night pages, which shows PDFs as light text on dark. A PDF opens on the page you left it. A locked PDF asks for its password. On a tablet or a wide screen, a page strip sits beside the document.

Tables

CSV, TSV and Excel files open as tables with the header row and the row numbers pinned while you scroll. Tap a column name for Sort smallest to largest, Sort largest to smallest, Column stats (sum, average, smallest, largest, most common values) and Copy the column. Excel files with several sheets show a tab for each sheet. More has Copy as CSV for the whole table, and a switch for files whose first row is data, not names; Settings sets the default.

Text, code and documents

Text, logs and code open with line numbers and wrap; both can be turned off in Settings. JSON has As saved and Tidy tabs, Markdown has Formatted and Source, and Word documents open as clean text. Bigger text and Smaller text are in More. Big files open fast: only the lines on screen are drawn, and a 52 MB log searches in a moment.

A file with the wrong name, like a picture saved as .bin, opens as what it really is, with a note. Anything Pure Peek cannot show opens as bytes.

Find

Find in this file works in text, code, tables and PDFs. Matches are marked, the current one stands out, and Previous match and Next match step through them. The count stops at 20,000 and shows 20,000+.

Web pages and SVG

HTML files and SVG drawings show inside the app with scripts off. Nothing outside the file is loaded, so a page cannot call home. Copy the source is in More.

Zip, audio, video and fonts

Zip
Walk the folders inside a zip and tap any file to open it, without unpacking the rest.
Audio and video
Play and pause, a seek bar, Back 10 seconds and On 10 seconds, speed, and Repeat. Audio shows its cover art and tags.
Fonts
A sample at every size and a box to try your own words.

Settings

Look
Follow the phone, Light, Graphite or True black. Follow the phone uses Light by day and True black at night.
Text and tables
Text size, wrap long lines, line numbers, and whether a table's first row holds the column names.
Privacy
Remember recent files. Turning it off forgets the list at once.
Opening files
Which app opens PDFs now, and how to make Pure Peek the one.
Widget
Open files, Open a folder and Photos in one tap on the home screen.
Help
This guide, the report page and the privacy policy.

Accessibility

Every control has a TalkBack label, touch targets are at least 48 dp, text grows with the phone's text size up to 200 percent, and text keeps a 7 to 1 contrast in every look.
