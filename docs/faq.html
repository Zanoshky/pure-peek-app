Questions and fixes

Pure Peek is not in the Open with list

Another app may be set to always open that kind of file. Open Android settings, Apps, that app, Open by default, and tap Clear defaults. Next time you tap a file, Android asks again. Settings, Opening files in Pure Peek names the app that opens PDFs now.

Can it edit files?

No. Pure Peek only shows files and never changes or resaves them. The Pro tools, like signing, make a new copy and leave the original alone.

What is free and what is Pro?

Opening and viewing every file type is free and never needs Pro. The tools are Pro: signing PDFs and photos, sorting a table and its column stats, black out, privacy copies and the rest under What Pro adds.

What is Support And Live API?

An optional subscription, 0.99 USD or EUR a month, for those who want to help more. It pays for bug fixes and new file formats. It unlocks nothing, and nothing is locked without it. Find it in Settings, under Support the developer. Cancel any time in Google Play.

Why can I not see where a photo was taken?

Android hides the place in a shared photo from apps that do not ask for the media location permission, and Pure Peek does not ask for it. About this file says when a photo has a place that Android hid. Share a privacy copy (Pro) still takes it out of the copy you send.

How big a file can it open?

We tested a CSV of 500,000 rows (20 MB) and a 52 MB log. Both open, scroll and search.

A file opens as bytes

Pure Peek shows anything it cannot read as bytes, with its size and checksum. If you think it should open, report it with the kind of file, and attach a sample if it holds nothing private.

Does it use the internet?

No. It has no internet permission, so Android itself stops it from going online. Web pages it shows load nothing from outside. See the privacy policy.
