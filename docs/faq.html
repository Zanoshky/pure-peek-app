Questions and fixes

Pure Peek is not in the Open with list

Another app may be set to always open that kind of file. Open Android settings, Apps, that app, Open by default, and tap Clear defaults. Next time you tap a file, Android asks again. Settings, Opening files in Pure Peek names the app that opens PDFs now.

Can it edit files?

No. Pure Peek only shows files and never changes or resaves them.

Why can I not see where a photo was taken?

Android hides the place in a shared photo from apps that do not ask for the media location permission, and Pure Peek does not ask for it. About this file says when a photo has a place that Android hid. Share a clean copy (Pro) still takes it out of the copy you send.

How big a file can it open?

We tested a CSV of 500,000 rows (20 MB) and a 52 MB log. Both open, scroll and search.

A file opens as bytes

Pure Peek shows anything it cannot read as bytes, with its size and checksum. If you think it should open, report it with the kind of file, and attach a sample if it holds nothing private.

Does it use the internet?

No. It has no internet permission, so Android itself stops it from going online. Web pages it shows load nothing from outside. See the privacy policy.
